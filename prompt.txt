DESIGN — NON-NEGOTIABLE RULES
═══════════════════════════════

TYPOGRAPHY:
- Use your UI UX Pro Max font pairing
- Display font for all headings
- Body font for paragraphs and UI text
- Google Fonts import only
- BANNED: Inter, Roboto, Arial, system-ui, Space Grotesk

COLOUR:
- Full CSS custom properties colour system
- Dominant colour + secondary + accent + background + text
- Contrast minimum 4.5:1 on all text
- No purple gradients on white — ever

DEPTH & ATMOSPHERE:
- Every section has visual atmosphere — 
  gradients, textures, layering, shadows
- Cards: box-shadow + hover lift transform
- Sections must feel distinct from each other
- At least one asymmetric or grid-breaking layout per page

MOTION:
- Hero: staggered CSS animation on load 
  (animation-delay per element)
- Scroll: IntersectionObserver fade/slide in main.js
- Hover: 150–300ms smooth transitions on all interactive elements
- prefers-reduced-motion respected in CSS

ICONS:
- SVG icons only — inline or from unpkg.com/heroicons
- ZERO emoji used as design elements

ANTI-PATTERNS — NEVER DO ANY OF THESE:
- Flat white cards on white backgrounds
- Generic hero with stock photo + white text overlay + nothing else
- WordPress-looking section layouts
- Lorem ipsum anywhere
- Review names with no review text
- Purple/pink AI gradient aesthetic
- Sections that look the same as each other
- Inter or Space Grotesk font
- Solid colour hero backgrounds

═══════════════════════════════
CODE STANDARDS
═══════════════════════════════

- HTML5 semantic elements throughout
- One styles.css, one main.js, shared across all pages
- CSS custom properties for colours, spacing, typography
- Mobile-first: breakpoints at 375px, 768px, 1024px, 1440px
- cursor: pointer on everything clickable
- Visible focus states for keyboard navigation
- All images: loading="lazy" + descriptive alt text
- NO frameworks, NO CSS libraries, NO JS libraries
- Only external dependency allowed: Google Fonts
- Clean, commented code
